# IM2ODE Examples

Collection of examples using IM2ODE with MatterSim and model potentials.

## Available Examples

### 1. TiO2_12atoms
Global structure search for TiO2 polymorphs (12 atoms)
- Calculator: MatterSim ML force field
- 4 Ti + 8 O atoms

### 2. Au20_cluster
Global optimization of 20-atom gold cluster
- Calculator: Gupta potential (LAMMPS)
- Famous tetrahedral pyramid structure
